## 1. Giới thiệu đề tài
**long2hand** là website bán đồ 2hand tối giản được xây dựng bằng HTML5, CSS3 và JavaScript thuần trên Visual Studio Code phục vụ Bài tập lớn A3 học phần FIT4014[cite: 13, 18, 24]. Giao diện sử dụng tông màu trung tính dịu mắt để không gây chói (`#FAF9F6` kem nhạt, `#FFFFFF` trắng ngà, `#F1EFEA` be xám nhạt, `#5C7065` xanh rêu trầm, `#2D3330` xám than)[cite: 29].
